# 마음빛 길잡이

초등 3학년이 카드나 한 문장으로 아침·하교 전 마음을 남기면, 선생님이 변화를 살펴보고 응원 한마디 초안을 받는 사회정서교육 도구.

## 실행

```bash
npm install
npm run dev        # http://localhost:3000 (같은 와이파이 태블릿은 http://<이 컴퓨터 IP>:3000)
npm test           # 살펴볼 학생·위험 표현 규칙 테스트
```

- 학생: 첫 화면에 6자리 코드, 또는 QR(`/join?c=코드`).
- 선생님: `/teacher`에서 이름 + 비밀번호. 처음부터 있던 반은 「홍북초」(`TEACHER_NAME`) / `TEACHER_PASSWORD`(없으면 1324). 「설정」에서 AI 키(업스테이지·Claude·ChatGPT·Gemini)와 시연 데이터.
- 여러 선생님: 로그인 화면의 「새 학급 만들기」로 누구나 가입(이름·학급 이름·숫자 비밀번호). 학급마다 저장 공간이 따로다(`inSpace(공간)` → 모음 앞이름 `maeumbit_<공간>_`). 이름 → 공간은 공간 밖 `accounts`, 선생님 표 `t:만료:판:공간`. AI 키는 학급마다 각자 넣는다. 가입 학급 수는 `MAX_CLASSES`까지(없으면 Turso 200, MongoDB 40 — MongoDB 무료는 모음 500개 한도). 새 학급은 인터넷 연결 하나에서 하루 10개, 모두 합쳐 하루 40개까지.
- 학생 코드는 모든 학급을 통틀어 하나뿐: `saveRoster`가 다른 학급 코드와 겹치면 새로 뽑고, 공간 밖 `codes` 색인(코드 → 학급)을 맞춘다. 학생 로그인은 코드로 학급을 찾고, 쿠키 `번호:코드:공간`.
- 심사용 체험(`/try`)의 선생님 화면은 `/teacher?try`로만 열린다. 그냥 `/teacher`로 오면 체험을 끝내고 로그인 화면을 보여 준다.

## 감정 단어 키우기
- 12가지 감정마다 더 꼭 맞는 말 3개(`lib/shared.ts`의 `NUANCE`). 학생이 카드에서 고르거나, 말로 하면 AI가 골라 준다(`word`).
- 반 감정 단어(교과서 연결로 더한 것)는 ⭐로 보인다. 주간 리포트에 이번 주·지난주 쓴 감정 단어 수를 비교한다.

## 교과서·학습지 연결
- 「📚 교과서 연결」에서 PDF·사진·HWP 등(4MB 안)을 올리면 업스테이지 Document Parse(`lib/upstage.ts`)가 글을 읽고, 고른 AI가 감정 단어·교실 활동을 뽑는다(`extractLesson`). 선생님이 고른 것만 반 감정 단어와 차시 목록에 저장. 업스테이지 키 필요.


## 활동지 피드백
- 「🖍️ 활동지 피드백」에서 학생 활동지(글·그림)를 스캔한 PDF를 올린다. 화면이 pdf.js(`pdfjs-dist`)로 쪽을 JPEG로 나누고, 스캔한 순서대로 1번부터 번호를 붙인다(건너뛸 번호: 전출·결석, 한 학생 1~4쪽).
- 학생 한 명씩 `/api/teacher/sheet`로 보낸다. Claude·ChatGPT·Gemini는 그림을 바로 보고, 업스테이지는 Document Parse(`ocr: force`, `mode: enhanced`)가 손글씨·그림 설명을 글로 바꾼 뒤 Solar가 쓴다(`sheetFeedback`).
- 기준: 교육부 한국형 사회정서교육 4대 핵심역량(자기감정·관계·공동체 가치·정신건강 인식·관리). 활동 주제·내용·피드백 기준은 비우면 AI가 판단. 결과: 읽은 내용, 잘 드러난 점·더 키워 볼 점(역량·근거), 학생에게 줄 말, 이렇게 쓴 이유, 살펴볼 내용.
- `sheets` 컬렉션에 번호로만 저장(이름·그림 없음). 학생용 쪽지 인쇄. 예시 PDF: `public/sample-sheets.pdf`.
- 연습 데이터(`seedPractice`)에는 예시 PDF 앞 5쪽(4번 건너뜀)을 피드백한 회차 하나(`demoSheetRun`, id `practice`)가 들어간다.

## 학생별 누적 기록
- 「📒 학생별 누적 기록」: 교사 화면은 34일 기록만 들고 있으므로 `studentAll` 동작이 한 학생의 처음부터 지금까지 기록·응원·메모·쪽지·돌아보기·활동지 피드백을 따로 읽는다. 모아 보기 숫자, 감정 흐름(전체·달마다), 자주 쓴 말, 4대 역량별 잘 드러남·키울 점, 날마다 기록 전체. 인쇄 가능.
## 학급 역량 진단(학생 화면 「마음 점검」)
- 근거: 한국형 사회정서교육 교육과정의 성취기준·내용체계와 한국교육과정평가원 사회정서역량 검사도구(KICE, 2024)를 바탕으로 마음빛이음 교사연구회가 만든 검사(따로 있던 「사회정서검사 역량앱」을 옮겨 왔다). 표준화·신뢰도 검증 전의 교육적 참고도구라고 화면에 밝힌다.
- 「🧭 학급 역량 진단」(기록·소통)에서 회차(학기 초·학기 말 등)를 열면 학생 화면 「더 해 보기」 맨 앞에 「마음 점검」이 생기고(안 했으면 「!」), 닫으면 사라진다. 열린 회차는 하나만. 닫은 뒤에도 선생님이 보낸 말을 학생이 아직 읽지 않았으면 그것만 보인다.
- 학생: 32문장(자기인식·관리 · 소통·협력 · 책임 · 마음돌봄 × 8, `lib/selfcheck.ts`)에 5단계(전혀 그렇지 않아요 ~ 매우 그래요)로 답한다. 한 화면에 한 문장, 읽어 주기, 5개 언어. 다 내면 점수·수준 없이 영역마다 나에게 맞는 이야기와 해 볼 일 3가지(세 단계 중 하나)가 보이고, 선생님이 보낸 말이 맨 위에 보인다. 회차가 열려 있는 동안은 다시 골라 고칠 수 있다.
- 선생님 「선생님 관찰 검사」(원래 앱의 교사 관찰 체크): 학생 번호를 하나씩 골라 간이 16 · 심층 32문항을 5단계로 고르고 선생님만 보는 메모와 함께 저장, 「저장하고 다음 학생」. 학생 답이 없어도 할 수 있고, 회차를 만들 때 「선생님 관찰만 하기」를 누르면 학생 화면에 열지 않은(닫힌 채로 만든, `teacherOnly`) 회차가 생긴다(「학생 화면에도 열기」로 나중에 열 수 있음). 학생별 표는 「학생 스스로 · 선생님 관찰」로 바꿔 볼 수 있다.
- 선생님 「결과 보기」: 영역별 점수(8~40)와 수준(만점의 85% 아주 잘함 · 65% 잘함 · 45% 자라나는 중 · 그 아래 도움 필요)을 반 평균 막대·수준별 학생 수·견줄 회차와 함께 보고, 학생별 표에서 학생을 고르면 스스로 답한 점수 ↔ 선생님 관찰 막대, 영역별 지도 가이드(현재 모습·지도 방향·마음빛 길잡이에서 함께 해 볼 것, `lib/selguide.ts`), 학생이 고른 32문장(종이 검사지로 옮긴 답이면 그렇다고 표시), 선생님 관찰(간이 16 · 심층 32), 종이 검사 점수 넣기, 선생님만 보는 메모, 학생에게 보낼 말(AI 초안 → 고쳐서 보내기 · 거두기, 읽음 표시)을 쓴다. 먼저 이야기 나눠 볼 학생: 도움 필요 영역 · 견준 회차보다 6점 넘게 내려감 · 스스로 본 모습과 관찰이 35%p 넘게 다름. 번호로만 보기·CSV(가명, 메모 빼고)·인쇄. 학생별 누적 기록에도 회차별 점수·관찰·보낸 말이 보인다.
- 선생님 「서면 검사」(종이로 하는 반): ① 검사지 인쇄 — 앱이 그린 A4 2쪽 검사지(네 귀퉁이 표식, 오른쪽 위 QR `MAM1|S|번호|쪽`, 큰 번호)를 반 전체 차례대로 · 번호 골라서 · 번호 없는 빈 검사지 n장으로 PDF를 만든다. 「내 양식에 번호·QR 찍기」는 선생님이 만든 학습지(PDF·사진, 6쪽까지)를 올리면 쪽마다 고른 귀퉁이에 QR(`MAM1|F|번호|쪽`)과 「n번」을 찍어 같은 방법으로 내보낸다. 이름 칸은 없다. ② 스캔본 올리기 — 반 전체를 한 번에 스캔한 PDF(120쪽까지)나 사진을 이 기기에서 쪽마다 그려(pdf.js) QR(jsQR)로 번호·쪽을 읽고, 표식 네 개로 기울기를 바로잡아(호모그래피) 체크 칸의 진하기와 칸 둘레 동그라미를 재서 32문장 답을 고른다(`lib/omr.ts`). 비었거나 두 칸이거나 흐린 칸은 주황으로 남기고, 「애매한 칸 AI로 읽기」를 누르면 그 칸과 빈 검사지의 손글씨 번호만 학생 한 명씩 AI에 묻는다(`/api/teacher/selscan`, 쪽 그림 JPEG 4장까지, 저장 안 함. Claude·ChatGPT·Gemini는 그림을 보고, 업스테이지는 Document Parse로 글로 바꿔 읽어 표시를 놓칠 수 있다고 알림). 내 양식은 칸 위치를 몰라 32문장을 모두 AI가 읽는다. 확인 표에서 번호·칸을 고친 뒤 저장하면 학생 답(`src: "paper"`)으로 들어가고, 화면에서 이미 답한 학생은 「종이 답으로 바꾸기」를 켜야 덮어쓴다. 같은 번호가 두 장이면 저장하지 않는다. ③ 영역 점수로 넣기 — 종이 검사 합계(영역마다 8~40)만 있으면 반 전체 한 표에 넣어 한꺼번에 저장(`selPaperScores`). 스캔 그림은 서버에 남기지 않는다.
- 저장: 회차 목록은 `meta/selfRounds`, 학생 답은 학생마다 `meta/self_<회차>_<번호>`, 선생님 쪽 기록(관찰·종이 점수·메모·보낸 말·읽은 시각)은 `meta/selnote_<회차>_<번호>`로 따로 둔다(학생 API는 이 문서에서 보낸 말만 읽어 보내고, 메모·관찰은 학생 화면과 AI로 가지 않는다). 번호를 새 학생에게 줬으면 앞 학생 답·기록은 보이지 않는다.
- AI 초안(`selDraft`): 영역별 수준(스스로·관찰)과 학생이 「매우 그래요」·「그렇지 않아요」 이하로 고른 문장 몇 개만 보낸다(이름·번호·메모 없음). 점수·수준 이름이 섞이면 한 번 다시 쓰게 하고, 그래도 남으면 화면에 표시한다.
- 예전 「반 전체 20문항 역량 진단」(`meta/selChecks`)과 10문장 「학생 자기진단」은 이 진단으로 바꿨다(예전 10문장 답은 읽지 않는다).
- 연습 데이터·체험 반: 학기 초(닫힘, 25명)·학기 말(열림, 20명) 회차, 17번(소통·협력 도움 필요, 관찰·메모·보낸 말)·3번(크게 내려감, 관찰·메모)·1·2번(보낸 말) 선생님 쪽 기록이 들어 있어, 체험 학생(5·8번은 아직 안 함)으로 들어가 바로 해 보고 1번으로 보낸 말을 볼 수 있다.

## AI 도우미(선생님 챗봇)
- 메뉴 「오늘 → AI 도우미」와, 다른 메뉴에서는 오른쪽 아래 단추(넓은 화면은 오른쪽 옆 창, 휴대폰은 전체 화면). 하위 화면: 대화 · 할 일 · 위기 대응 · 자료함.
- 대화(`/api/teacher/assist` ask): 물음에 맞춰 서버가 모은 것만 근거로 답한다 — [할 일](앱이 찾은 일 + 선생님 업무 목록), [학생 N번](물음의 「N번」·가명, 「이 학생」이면 보던 학생: 최근 30일 기록·앱 신호·응원·쪽지 수·역량 진단 수준. 면담 메모, 위험 표현 조치 기록, 역량 진단 메모는 보내지 않는다(개인정보 안내·보호자 동의서의 약속)), [우리 반 최근 2주](반 전체를 물을 때), [대응 안내](위기 말이 있을 때 `lib/crisis.ts` 고정 글 + 학교 연락처), [자료](`lib/kb.ts` 기본 자료 카드 + 자료함 조각, 바이그램·IDF로 찾기). 답은 JSON(reply·todos·go·sources)으로 받아 정해진 화면·학생·자료 이름만 남긴다(`cleanAssist`).
- 실명은 선생님 기기에만 있으므로 보내기 전에 화면이 번호로 바꾼다(`hideNames`). 대화는 `meta/chat_<id>`(kind chat)에 남기고 마지막으로 쓴 날부터 30일 지나거나 30개를 넘으면 지운다. 체험 반은 대화를 남기지 않는다.
- 기본 자료(`lib/kb.ts`): 선생님 드라이브의 2026 사회정서교육 자료(교육부·한국교육환경보호원 「한국형 사회정서교육 프로그램」 초등 저·고학년 지도서, 「한국형 사회정서교육 교육과정」(2025.12), 연수 자료 「오해와 진실」·「2022 개정 교육과정 연계 방안」)를 요약한 카드 15장. 원문은 옮기지 않았다.
- 위기 대응(`lib/crisis.ts`, AI 없이도 보임): 학교폭력(충남교육청 2026 사안처리 길라잡이 요약), 아동학대 의심(아동학대처벌법 제10조·제63조, 신고의무·면담 요령), 자살·자해 위험(혼자 두지 않기·직접 묻기·즉시 공유, 109·1388 등). 기준일 2026-11-12. 우리 학교 연락처는 `meta/assistContacts`.
- 할 일: 앱이 찾은 일(위험 표현 알림, 허락 기다리는 쪽지, 먼저 살펴볼 학생, 역량 진단 미응답·피드백 안 보낸 학생, 보관 기한 지난 기록, 금요일 주간 리포트, 동의서) + 선생님 업무 목록 `meta/assistTodos`(마감일, 대화에서 「할 일에 넣기」).
- 자료함: 업무 계획·공문·연수 자료(20개, 한 개 12만 자, 모두 60만 자까지). 글이 든 PDF·TXT는 기기에서 읽고(pdf.js, 한글 CMap은 `public/pdfjs-cmaps`), HWP·HWPX·DOCX·PPTX·XLSX·스캔 PDF는 `/api/teacher/assist/parse`(업스테이지 Document Parse)로 글만 뽑는다. 글은 `meta/assistDoc_<id>`, 목록은 `meta/assistDocs`. 체험 반은 올릴 수 없다.

## 위험 표현 조치 기록
- 마음 지도의 위험 표현 「살펴봤어요」를 누르면 한 일(학생과 이야기 나눔 · 보호자 연락 · Wee클래스·상담교사 연계 · 관리자·담당 교사 보고 · 계속 지켜보기 · 걱정할 내용이 아니었음, 여럿)과 한 날·짧은 메모를 남겨야 알림이 닫힌다.
- 그 뒤에 더 한 일은 마음 지도 학생 창·학생별 누적 기록의 「위험 표현과 조치」에서 「조치 더 적기」로 같은 기록에 이어 적는다. `meta/riskActions` 한 문서(500건까지). 선생님만 보고 AI에는 보내지 않는다.
- 상담 의견서 「4. 담임이 해 본 지원」에 미리 채워지고, 주간 리포트 위험 표현 줄과 CSV 「한 일(조치)」 칸에 들어간다.

## 기록 보관·정리 · 보호자 동의

## 마음 친구 그림(손그림 2D 애니메이션)
- three.js를 빼고 SVG로 새로 그렸다(`components/buddy/`). 극장판 셀 애니메이션처럼: 따뜻한 세피아 잉크선(아래·오른쪽이 굵음), 한 단계 셀 그림자(차가운 보라 쪽), 반사광·윤기 한 줄, 몸에 물감 결. WebGL이 없어 어느 태블릿에서나 같은 모습이다.
- 배경 구름은 왼쪽→오른쪽 · 오른쪽→왼쪽으로 흐르는 것과 제자리에 떠 있는 것이 섞여 있다(구름 층은 1초 4번만 다시 그림).
- 움직임은 1초 24장(「원스」)으로 부드럽게 바뀌고, 선은 1초 8번만 잡음 씨앗을 바꿔 다시 그린 듯 떨린다(boil, `feTurbulence`+`feDisplacementMap`). 화면 밖이면 멈추고, 「동작 줄이기」 설정이면 한 장만 그린다.
- 표정은 48가지: 큰 감정 12가지와 「더 꼭 맞는 말」 36가지가 저마다 따로다(`components/buddy/expr.ts`의 `EXPR`, 겹치지 않음을 `lib/expr.test.ts`가 확인). 예) 뿌듯해요는 가슴을 펴고 금메달, 설레요는 하트 눈에 두근두근, 멍해요는 흰 눈에 빙글빙글, 기운 없어요는 녹아내리며 빈 건전지, 깜짝 놀랐어요는 튀어나온 눈과 느낌표, 창피해요는 >< 눈으로 얼굴을 가리고 배배 꼼, 부글부글해요는 머리 위로 거품이 끓어오름. 학생이 고른 「더 꼭 맞는 말」이 있으면 그 표정으로 보여 준다(기록 화면·꾸미기·한 주 돌아보기·선생님 화면 얼굴). 표정 재료는 눈(^^·별·하트·웃는 눈·멍한 눈·튀어나온 눈·반쯤 감김·졸림·걱정·놀람·눈물 고임·찡그림·꼭 감음 >< 등) · 눈썹 · 입(활짝·ω·물결·삐죽·이 악물기·하품 등) · 볼(발그레 빗금) · 몸짓(통통 뛰기·춤·살랑·둥실·두리번·축 처짐·꾸벅·안절부절·덜덜·한숨·발 구르기·부르르) · 효과(반짝임·별·음표·하트·꽃잎·말줄임·zzz·땀·떨림·그늘 선·눈물·비구름·한숨·김·핏줄·!?). 「더 꼭 맞는 말」은 큰 감정의 표정을 따르고, 세기(1~5)만큼 크게 움직인다.
- 인사: 기쁜 마음은 폴짝 두 번(웅크림→늘어남→찌그러짐) + 손 흔들기, 힘든 마음은 끄덕이며 가슴을 토닥이고 하트. 숨 고르기는 들이쉬며 부풀고 내쉴 때 「후~」, 꼭 쥐었다 펴기는 >< 눈으로 부르르 떨다 「휴~」.
- 큰 자리(체험·꾸미기·마음 다스리기·한 주 돌아보기·감정 단어 놀이·교실 TV)에는 `scene`으로 배경 장면을 함께 그린다. 배경은 선 없이 수채·과슈처럼 칠하고(인물은 선, 배경은 물감) 감정 무리마다 바뀐다: 기쁨 맑은 여름 하늘·나비, 평온 오후 햇살·민들레 씨, 슬픔 비·웅덩이, 화남 노을·바람에 날리는 잎, 불안 달밤·반딧불.
- 학생 첫 화면(코드 넣기) 위에는 코드 칸과 같은 너비의 넓은 들판 그림(`BuddyParade`, 가로 8:세로 5)에 모습이 다른 마음 친구 다섯이 저마다 다른 마음으로 논다. 7초마다 왼쪽 친구부터 차례로 폴짝 인사(파도타기)하고, 뛰어오른 사이에 다음 마음 표정으로 바뀐다(누가 어디서 어떤 마음인지는 `components/buddy/parade.ts`).
- 마음 친구 이름은 학생이 실명을 쓸 수 있어 선생님 화면으로 보내지 않는다.
- 저장하면 감정에 맞게 인사(기쁨은 폴짝, 힘든 마음은 토닥). 슬픔·화남·불안을 남기면 「같이 숨 고르기」(4초 들이쉬고 4초 내쉬기 3번, `components/Breathe.tsx`)를 권한다. 내 마음 달력에도 마음 친구가 나온다.

## 심사용 체험 링크(/try)
- 비밀번호·학생 코드 없이 가짜 반(가명 25명, 최근 7일)으로 들어간다. `mb_demo` 쿠키가 있는 요청은 `inSpace("demo")`(AsyncLocalStorage)로 돌아 모음 이름 앞에 `demo_`가 붙는다 → 실제 반과 저장 공간부터 따로.
- 선생님 표에 공간 표시(`:d`)가 있어 체험 표로 실제 반을, 실제 반 표로 체험 공간을 열 수 없다(`lib/auth.test.ts`).
- 체험에서는 비밀번호·AI 키 바꾸기와 휴대폰 알림을 막는다. AI는 하루 200번까지(`DEMO_AI_PER_DAY`). 날짜가 바뀌거나 연습 데이터의 판(`PRACTICE_VERSION`)이 바뀌면 처음 판으로(새 버전을 올린 날에도 역량 진단 회차 같은 새 연습 데이터가 바로 보이게).
- 체험이 쓰는 AI 순서: ① 공용 업스테이지 키 `UPSTAGE_API_KEY`(모델 `UPSTAGE_MODEL`, 비우면 기본 Solar) → ② 체험 전용 키 `TRIAL_AI_KEY`·`TRIAL_AI_PROVIDER`(upstage·claude·openai·gemini)·`TRIAL_AI_MODEL` → ③ 홍북초 반에 넣은 키를 빌려 씀. 교과서 읽기(Document Parse)는 업스테이지 키일 때만.
- 공용 업스테이지 키는 실제 학급도 함께 쓴다: 「설정」에 고른 AI의 키가 없으면 학급마다 하루 `SHARED_AI_PER_DAY`번(비우면 100, 0이면 끔)까지 이 키로 돈다(`meta/sharedAiUsage`). 선생님이 넣은 키가 있으면 그 키를 먼저, 제한 없이. 다른 AI를 콕 집어 부르는 기능(Gemini 음성 듣기)은 빌리지 않는다. 「설정」의 AI 연결에 오늘 쓴 횟수가 보인다(`lib/shared-ai.test.ts`).
- 비밀 키는 Vercel의 Production과 Preview에 함께 체크해 두면 PR 미리보기의 체험·학급도 같은 키로 돈다(미리보기 사용 횟수는 미리보기 데이터베이스에서 따로 센다).
- 연습 데이터는 기록을 한꺼번에 저장(`setMany`)해 몇 초면 만들어진다.

- 감정 낱말 카드 72장(큰 감정 12 · 더 꼭 맞는 말 36 · 더한 낱말 24)은 그 감정 색을 입은 마음 친구가 저마다 다른 표정을 짓는 그림이다(`EmotionArt` → `BuddyFace`). 달력·한 주 돌아보기·감정 단어 사전·선생님 화면 기록에도 고른 말의 표정이 그대로 나온다.

- 까닭 카드 5장·마음 꽃·체험 화면의 선생님/학생 그림·교실 TV 날씨 8가지·마음 다스리기 도구와 오감 찾기도 같은 그림체. 「지금 마음은 어때?」 고르기에는 내 마음 친구가 그 표정을 지어 보인다.
- 남은 이모지는 휴대폰 위험 알림 제목의 ⚠️ 하나(운영체제 알림이라 그림을 넣을 수 없음).

## AI 글투(번역투·기계식 표현 피하기)
- 선생님 글(응원 한마디 초안·활동지 피드백·상담 의견서 초안·주간 요약과 활동 추천·교과서 활동 정리)과 학생 화면의 AI 말(되묻기·마음 친구 답, 한국어일 때)에 같은 글투 규칙을 붙인다(`lib/style.ts`의 `STYLE_RULES`): 「~를 통해」→「~로」, 이중 피동 금지, 「~에 있어서·~에 관하여」 같은 번역 조사 대신 일상 조사, 「다양한 요인」 대신 구체적인 이유, 영어식 대명사 빼기, 「첫째·둘째」 번호 대신 이어 쓰기, 「결론적으로·요약하자면」 없이 핵심부터, 「시사하는 바가 크다」 같은 빈말 평가·과장 어휘·「~가 아니라 ~다」 대조 되풀이 피하기.
- AI가 쓴 뒤 서버가 확실한 것만 바로 고친다(`polish`): 이중 피동(보여진다→보인다, 되어졌다→되었다…), 「이에 있어서」→「여기서」, 「관계·생활·학습…에 있어서」→「~에서」, 문장 앞 「결론적으로·요약하자면」 빼기. 따옴표 안의 학생 말은 건드리지 않는다.
- 뜻이 바뀔 수 있어 바로 고치지 못한 것(「~를 통해」·「첫째·둘째」·빈말 평가 등)은 `styleHits`로 찾아 초안 아래에 「다듬으면 더 자연스러워요」로 알린다(AI를 다시 부르지 않아 사용 횟수는 그대로).

## 한국어 줄바꿈
- 화면 전체에 `word-break: keep-all`을 걸어 한국어 줄글이 낱말 가운데(「합니/다」)에서 끊기지 않고 띄어쓰기 자리에서만 줄을 바꾼다. 칸보다 긴 낱말만 넘칠 때 끊는다(`overflow-wrap: break-word`). 띄어쓰기가 없는 중국어·일본어 학생 화면은 그대로 글자마다 줄을 바꾼다.

## 학생 화면을 쉽게
- 카드로 남길 때는 한 화면에 질문 하나씩: 감정 카드 → (더 꼭 맞는 말, 안 골라도 됨) → 마음 크기 → 까닭.
- 감정 카드는 낱말 72장(긍정·보통·부정 24장씩, `CARD_WORDS`) 중 열 때마다 무작위 12장을 긍정 4 · 보통 4 · 부정 4로 뽑는다(`drawCards`, 한 큰 감정은 두 장까지·보통은 세 장까지). 마음에 드는 카드가 없으면 「다른 카드로 바꾸기」로 한 번만, 처음 12장과 겹치지 않는 12장을 다시 뽑는다. 큰 감정 카드를 고르면 더 꼭 맞는 말로, 낱말 카드를 고르면 바로 마음 크기로 간다. 낱말은 기록에서 큰 감정 12가지 아래로 묶여(`word`) 선생님 화면·규칙·TV 날씨는 그대로다(`lib/cards.test.ts`). 누르면 바로 다음 화면으로 넘어가고, ← 로 돌아가며, 위의 점 네 개로 몇 번째인지 보인다. 고르는 동안 마음 친구가 그 표정을 바로 지어 보인다(`components/MoodPicker.tsx`의 `stepwise`). 말로 한 뒤 고칠 때만 세 가지를 한 화면에.
- 위쪽 읽어 주기는 스피커 그림 단추 하나, 언어는 지구 그림 고르기 하나로 작게.

## 선생님 화면을 쉽게
- 메뉴는 오늘·아이 돌보기·기록·소통·수업·관리 다섯 묶음으로 모두 펼쳐 둔다(세로 태블릿에서도 한 번에 보임). 메뉴 그림은 마음 친구와 같은 손그림 그림(`components/Doodle.tsx`).
- 「설정」은 처음에 비밀번호·AI 키·반 이름·기록 내보내기만 보이고, 휴대폰 알림·모델 이름·단어 목록·말투·살펴볼 학생 규칙·연습 데이터는 「자세한 설정 펼치기」 안에.

## 브라우저(태블릿) 뒤로 가기
- 학생 화면은 한 주소 안에서 단계가 바뀌므로, 단계가 깊어질 때마다 같은 주소로 기록을 하나 쌓아 뒤로 가기가 앞 단계로 돌아가게 한다(`lib/back.ts`의 `useBackSteps`). 마음 남기기(고르기 → 감정 카드 → 더 꼭 맞는 말 → 마음 크기 → 까닭 → 되묻기, 말하기 → 확인 → 되묻기), 마음 다스리기 도구 상자(도구 고르기 → 도구 → 다 한 뒤), 마음 점검(앞 문장으로). 저장한 뒤에는 고르기 화면으로.
- 화면 안 「←」 단추로 돌아가면 쌓아 둔 기록을 조용히 걷어 내 둘이 어긋나지 않는다. 기록마다 몇째 단계인지(`mbBack`)를 적어 두고, 뒤로 가기로 도착한 단계까지 꺼낸다.
- 학생 첫 화면에서 뒤로 가기를 눌러도 앱 밖으로 나가지 않고 「다른 친구로 바꾸려면 다음 친구 차례를 눌러요」를 잠깐 보여 준다(`useBackGuard`). 더 해 보기 화면(돌아보기·놀이 등)은 원래대로 뒤로 가기로 학생 첫 화면에 돌아온다.

## 학생 「더 해 보기」
- 🗓️ 한 주 돌아보기(`/me/week`): 월요일부터의 내 마음 스티커 + 「이번 주 나는…」 한 줄 → 마음 친구(AI, 학생 언어)의 답. 위험 표현이면 고마움만 말하고 선생님께 알림. `reflects`에 저장, 선생님은 학생 상세에서 본다.
- 🎲 감정 단어 놀이(`/me/game`, `lib/game.ts`): 상황 15개(5개 언어) → 보기 3개. 반 감정 단어가 정답인 문제가 먼저. 점수·순위 없음.
- 📖 우리 반 감정 단어 사전(`/me/words`): 36개 단어 쉬운 뜻 + 최근 두 달 반 전체 사용 횟수(이름 없이) + 내가 써 봤는지.
- 💌 공감 쪽지(`/me/letters`): 친구에게 120자, 이름 공개/비공개는 학생이 고름, 하루 5통. 선생님이 「✉️ 공감 쪽지」에서 허락해야 전해진다.
- 🌱 마음 친구 성장: 써 본 서로 다른 감정 단어 수로 꾸미개가 열린다(`ACC_UNLOCK`, 서버에서도 확인).
- 📶 끊김 대비: 저장이 서버까지 못 가면 기록과 그날 표(qtoken)를 기기에 담아 두고, 다시 들어오거나 연결되면 `saveQueued`로 보낸다(`lib/queue.ts`).

## 읽기량(Firestore)

- 교사 화면은 20초마다 변경 표시 문서(`meta/stamp`) 하나만 읽고, 기록이 바뀌었을 때만 그 뒤 바뀐 기록(`updatedAt`)만 받아 합친다.

## 저장소

- 고르는 순서: `TURSO_DATABASE_URL`(+`TURSO_AUTH_TOKEN`)이 있으면 Turso(libSQL), 없고 `MONGODB_URI`가 있으면 MongoDB Atlas(데이터베이스 이름 `MONGODB_DB`, 기본 `maeumbit`), 없고 `FIREBASE_SERVICE_ACCOUNT`가 있으면 Firestore(`maeumbit-gil`, 서울), 모두 없으면 `.data/db.json`.
- Turso(`lib/turso.ts`): 모든 모음을 표 하나 `docs(col, id, data JSON, v)`에 둔다. `col`은 몽고 모음 이름과 같다(`maeumbit_<공간>_records` 등). 찾는 칸(`no`·`date`·`createdAt` 등, `INDEXED`)마다 (col, 칸) 식 색인. 새 칸으로 `find`·`count`·`delWhere`를 하게 되면 `INDEXED`에 더한다. `update`는 표 `v`로 비교 후 쓰기, `setField`·`bump`는 SQL 한 문장. Turso에는 서울 지역이 없어(가장 가까운 곳이 도쿄, 한 번 오가는 데 40ms쯤) 같은 순간(이벤트 한 바퀴)에 들어온 읽기·쓰기를 각각 요청 하나로 묶고, 방금 읽은 판은 `update`가 처음 한 번 그대로 써 본다. 화면 코드도 서로 기다릴 필요 없는 읽기는 함께 시작한다(선생님 화면 7→2번, 학생 화면 4→2번, 저장은 응답까지 2번). `TURSO_SIM_MS=40 TURSO_DEBUG=1`로 로컬에서 먼 저장소를 흉내 내 몇 번 오가는지 볼 수 있다. 시험: `TURSO_DATABASE_URL=file:t.db npm test`로 모든 시험을 Turso로 한 번 더 돌릴 수 있다.
- 몽고 → Turso 옮기기·속도 재기·저장소 점검: `/admin/db`(실제 배포에서는 운영 선생님(홍북초)으로 들어온 사람만, 미리보기는 Vercel 로그인한 사람만). 실제 앱은 2026-11-13부터 Turso(`mam`, 도쿄)로 돈다. 바꿔치기·되돌리기는 `docs/turso-swap.md`. 「복사하기」는 그 배포의 `MONGODB_DB`에서 `maeumbit_`로 시작하는 모음을 모두 옮기고 모음마다 수·내용을 맞춰 본다(몽고는 읽기만). 「속도 재기」는 두 저장소의 `bench` 공간에 같은 일을 시켜 시간을 견주고 지운다.
- PR 미리보기(Vercel Preview)는 실제와 같은 클러스터의 다른 데이터베이스를 쓴다: Preview에만 `MONGODB_DB=maeumbit_preview`. Preview에 `MONGODB_URI`를 넣어야 MongoDB로 돌고, 없으면 Firestore로 돈다. 미리보기에서 무엇을 눌러도 실제 반 기록·계정과 섞이지 않는다.
- MongoDB Atlas 무료(M0)는 하루 읽기 한도가 없다(저장 512MB). Vercel에서 붙으려면 Atlas 「Network Access」에 `0.0.0.0/0`을 허용해야 한다(Vercel 서버 주소가 바뀌므로). 그래서 DB 사용자 비밀번호를 길고 무작위로 둔다.
- Firestore에서 옮기기: `FIREBASE_SERVICE_ACCOUNT=… MONGODB_URI=… node scripts/copy-to-mongo.mjs maeumbit_` (같은 `SESSION_SECRET`이면 넣어 둔 AI 키도 그대로 풀린다).
- Firestore 규칙은 브라우저 접근을 모두 막는다(`firestore.rules`). 읽기·쓰기는 서버의 관리자 SDK만.
- 교사가 넣은 API 키는 `SESSION_SECRET`으로 암호화해 저장한다. 이 값을 바꾸면 키를 다시 넣어야 한다.

## Vercel 배포

환경 변수 `SESSION_SECRET`, `FIREBASE_SERVICE_ACCOUNT`, `TEACHER_PASSWORD`(4자리보다 길게)를 넣고 배포한다. `.env.example` 참고.
