# 마음빛 길잡이

초등 3학년이 카드나 한 문장으로 아침·하교 전 마음을 남기면, 선생님이 변화를 살펴보고 응원 한마디 초안을 받는 사회정서교육 도구.

## 실행

```bash
npm install
npm run dev        # http://localhost:3000 (같은 와이파이 태블릿은 http://<이 컴퓨터 IP>:3000)
npm test           # 살펴볼 학생·위험 표현 규칙 테스트
```

- 학생: 첫 화면에 6자리 코드, 또는 QR(`/join?c=코드`).
- 선생님: `/teacher`, 비밀번호 `TEACHER_PASSWORD`(없으면 1324). 「설정」에서 AI 키(업스테이지·Claude·ChatGPT·Gemini)와 시연 데이터.

## 감정 단어 키우기
- 12가지 감정마다 더 꼭 맞는 말 3개(`lib/shared.ts`의 `NUANCE`). 학생이 카드에서 고르거나, 말로 하면 AI가 골라 준다(`word`).
- 반 감정 단어(교과서 연결로 더한 것)는 ⭐로 보인다. 주간 리포트에 이번 주·지난주 쓴 감정 단어 수를 비교한다.

## 교과서·학습지 연결
- 「📚 교과서 연결」에서 PDF·사진·HWP 등(4MB 안)을 올리면 업스테이지 Document Parse(`lib/upstage.ts`)가 글을 읽고, 고른 AI가 감정 단어·교실 활동을 뽑는다(`extractLesson`). 선생님이 고른 것만 반 감정 단어와 차시 목록에 저장. 업스테이지 키 필요.

## 이번 주 마음 요약·다음 주 활동 추천
- 주간 리포트의 「AI로 만들기」. 이름·번호 없이 모은 숫자(`weekStats`)만 AI에 보내 흐름 3줄과 활동 2가지를 만든다. 교과서 연결 활동이 있으면 그중에서 먼저 고른다.

## 이주배경학생(영어·중국어·베트남어·일본어)
- 학생 화면 위 🌐에서 언어를 고르면(기기에 학생별로 저장) 화면 문구·감정 이름·읽어 주기·음성 인식·AI 되묻기가 그 언어로 바뀐다(`lib/i18n.ts`). 감정 카드에는 한국어도 함께 보여 우리말 감정 단어를 익힌다.
- 선생님 화면에는 언제나 한국어 요약(`summaryKo`)과 원문, 🌐 언어 표시가 보인다.

## 선생님 비밀번호
- 처음에는 `TEACHER_PASSWORD`(없으면 1324). 「설정 → 선생님 비밀번호 바꾸기」에서 숫자 4~12자리로 바꾸면 scrypt 해시로 `meta/pin`에 저장한다(`lib/auth.ts`).
- 바꾸면 비밀번호 판(v)이 올라가 다른 기기의 선생님 화면은 잠긴다. 잊었으면 저장소의 `meta/pin` 문서를 지우면 처음 비밀번호로 돌아간다.

## 마음 친구 꾸미기
- 학생 화면 「🎨 마음 친구 꾸미기」(`/me/buddy`): 몸 색(기본은 감정 색) · 모양(동글이·말랑이·콩알이) · 눈(콩알·반짝·왕눈) · 볼(발그레·주근깨) · 무늬(점박이·배 무늬) · 팔다리(팔·팔과 발) · 꾸미개(새싹·리본·고깔모자·왕관·안경·고양이 귀·토끼 귀·꽃·헤드폰) · 이름. `meta/looks`에 번호별로 저장, 예전 모습에 없는 항목은 기본값(반짝 눈·발그레·팔)으로 채운다.
- 고르는 동안에는 움직이지 않는다. 저장하면 제자리에서 폴짝 뛰며 손을 흔든다(돌지 않음).
- 3D 사용 가능 여부는 한 번만 재서 기억한다(그릴 때마다 시험용 WebGL을 만들면 브라우저 한도를 넘어 3D가 꺼짐).
- 몸 색을 골라도 감정은 표정·움직임·둘레 빛으로 보인다(`components/Buddy.tsx`). 3D가 안 되는 기기와 선생님 화면은 같은 모습의 2D 얼굴(`components/BuddyFace.tsx`).
- 마음 친구 이름은 학생이 실명을 쓸 수 있어 선생님 화면으로 보내지 않는다.
- 저장하면 감정에 맞게 인사(기쁨은 폴짝, 힘든 마음은 토닥). 슬픔·화남·불안을 남기면 「같이 숨 고르기」(4초 들이쉬고 4초 내쉬기 3번, `components/Breathe.tsx`)를 권한다. 내 마음 달력에도 마음 친구가 나온다.

## 마음 다스리기 도구 상자
- 힘든 마음(슬픔·화남·불안)을 남기면 권하고, 마음 친구 옆 「🧰 마음 다스리기」로 언제든 연다(`components/CalmBox.tsx`).
- 숨 고르기(부풀었다 줄어듦) · 꼭 쥐었다 펴기(움츠렸다 풀림) · 5-4-3-2-1 찾기(보이는 것 5 … 나에게 해 줄 좋은 말 1) · 마음 그리기(저장 안 함).
- 끝나면 「지금 마음은 어때?」(조금 나아졌어요·그대로예요·잘 모르겠어요)를 그 시간 기록의 `calm`에 붙인다. 선생님은 2주 기록의 🧰 표시와 주간 리포트(도구별 횟수·나아짐, `calmStats`)로 본다.

## 우리 반 마음 날씨(교실 TV)
- 선생님 화면 「📺 교실 화면」 → `/teacher/tv`. 선생님 로그인이 필요하고, 서버는 이름·번호·위험 표현 없이 감정 무리 수·감정 단어만 보낸다(`classWeather`).
- 날씨: 절반 넘는 무리로 맑음·포근함·비·천둥번개·안개, 섞이면 구름 조금·흐림·알록달록. 3명보다 적게 남겼으면 숫자를 숨긴다.
- 마음 친구 행렬은 꾸미지 않은 기본 모습으로 감정 순서대로만 보여 누구인지 알 수 없게 한다. 30초마다 새로 읽고, 화면 높이에 맞춰 1280×720 프로젝터에서도 한 화면에 들어온다.

## 심사용 체험 링크(/try)
- 비밀번호·학생 코드 없이 가짜 반(가명 25명, 최근 7일)으로 들어간다. `mb_demo` 쿠키가 있는 요청은 `inSpace("demo")`(AsyncLocalStorage)로 돌아 모음 이름 앞에 `demo_`가 붙는다 → 실제 반과 저장 공간부터 따로.
- 선생님 표에 공간 표시(`:d`)가 있어 체험 표로 실제 반을, 실제 반 표로 체험 공간을 열 수 없다(`lib/auth.test.ts`).
- 체험에서는 비밀번호·AI 키 바꾸기와 휴대폰 알림을 막는다. AI는 하루 200번까지(`DEMO_AI_PER_DAY`). 날짜가 바뀌면 처음 판으로.
- 체험 전용 AI 키: Vercel 환경 변수 `TRIAL_AI_KEY`(필수)·`TRIAL_AI_PROVIDER`(upstage·claude·openai·gemini, 기본 upstage)·`TRIAL_AI_MODEL`(선택). 있으면 그 키만 쓰고, 없으면 실제 반에 넣은 키를 빌려 쓴다. 교과서 읽기(Document Parse)는 업스테이지 키일 때만.
- 연습 데이터는 기록을 한꺼번에 저장(`setMany`)해 몇 초면 만들어진다.

## 학생 「더 해 보기」
- 🗓️ 한 주 돌아보기(`/me/week`): 월요일부터의 내 마음 스티커 + 「이번 주 나는…」 한 줄 → 마음 친구(AI, 학생 언어)의 답. 위험 표현이면 고마움만 말하고 선생님께 알림. `reflects`에 저장, 선생님은 학생 상세에서 본다.
- 🎲 감정 단어 놀이(`/me/game`, `lib/game.ts`): 상황 15개(5개 언어) → 보기 3개. 반 감정 단어가 정답인 문제가 먼저. 점수·순위 없음.
- 📖 우리 반 감정 단어 사전(`/me/words`): 36개 단어 쉬운 뜻 + 최근 두 달 반 전체 사용 횟수(이름 없이) + 내가 써 봤는지.
- 💌 공감 쪽지(`/me/letters`): 친구에게 120자, 이름 공개/비공개는 학생이 고름, 하루 5통. 선생님이 「✉️ 공감 쪽지」에서 허락해야 전해진다.
- 🌱 마음 친구 성장: 써 본 서로 다른 감정 단어 수로 꾸미개가 열린다(`ACC_UNLOCK`, 서버에서도 확인).
- 📶 끊김 대비: 저장이 서버까지 못 가면 기록과 그날 표(qtoken)를 기기에 담아 두고, 다시 들어오거나 연결되면 `saveQueued`로 보낸다(`lib/queue.ts`).

## 선생님 화면
- 넓은 화면(1024px 이상)은 왼쪽 세로 메뉴, 좁은 화면은 ☰ 서랍 메뉴. 보던 메뉴는 기기에 기억. 위험 표현·허락 기다리는 쪽지 수를 메뉴에 표시.
- 📝 상담 의견서: 최근 2주 기록(가명)으로 AI가 관찰 사실 3칸 초안(진단명 금지), 면담 메모는 AI에 보내지 않고 칸에만 채움. A4 인쇄.
- 🏠 가정 소식지: 반 전체 이야기만(이름 없음), 집에서 해 볼 마음 놀이, AI 번역본(영·중·베·일). 자동 발송 없음.
- 📺 교실 화면에 「📖 단어 사전」 보기(최근 30일 반 감정 단어, 많이 쓸수록 크게).

## 말투(목소리 기운)

설정 → 「말투 살피기」에서 고른다. 선생님 화면에만 보인다.

- 끄기: 말 내용으로만 정리.
- 기기 안에서 재기(기본): 브라우저가 소리 크기·높낮이·빠르기를 숫자로만 재서(`lib/voice.ts`) 그 학생의 평소 목소리(이전 말하기 기록 3번 이상의 가운데값)와 비교한다(`lib/tone.ts`). 결과는 고른 AI(업스테이지 포함)가 감정을 정리할 때 함께 참고한다.
- Gemini가 직접 듣기: 16kHz WAV를 Gemini에 보내 말투까지 판단(저장 안 함). Gemini 키 필요, 실패하면 기기 재기로.

## 선생님 앱(PWA)·휴대폰 알림

- `/teacher`에만 매니페스트(`public/teacher.webmanifest`)가 붙어 선생님 화면을 앱으로 설치한다(안드로이드 크롬 「앱 설치」, 아이폰 Safari 「홈 화면에 추가」).
- 「설정 → 휴대폰으로 위험 표현 알림 받기」로 기기를 등록하면, 학생 기록에 위험 표현이 들어올 때 웹 푸시가 간다(`lib/push.ts`, `public/sw.js`). 알림에는 번호만 담는다.
- 환경 변수 `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`가 필요하다.

## 읽기량(Firestore)

- 교사 화면은 20초마다 변경 표시 문서(`meta/stamp`) 하나만 읽고, 기록이 바뀌었을 때만 그 뒤 바뀐 기록(`updatedAt`)만 받아 합친다.
- 교사 기기에 최근 기록을 저장해 두고(`localStorage`, 잠그면 지움) 다시 열 때도 그 뒤 바뀐 기록만 받는다. 기록을 지우면 `meta/stamp.wipe`가 바뀌어 저장해 둔 것을 버린다.
- Firebase 무료(Spark) 요금제는 하루 읽기 5만 번이 한도다(미국 태평양 자정, 한국 16~17시에 초기화). 여러 반이 쓰면 Blaze(종량제)로 올린다.
- 학생 화면은 자기 번호 기록만 읽는다. 전체 읽기는 CSV 내보내기뿐.

## 저장소

- 고르는 순서: `MONGODB_URI`가 있으면 MongoDB Atlas(데이터베이스 이름 `MONGODB_DB`, 기본 `maeumbit`), 없고 `FIREBASE_SERVICE_ACCOUNT`가 있으면 Firestore(`maeumbit-gil`, 서울), 둘 다 없으면 `.data/db.json`.
- MongoDB Atlas 무료(M0)는 하루 읽기 한도가 없다(저장 512MB). Vercel에서 붙으려면 Atlas 「Network Access」에 `0.0.0.0/0`을 허용해야 한다(Vercel 서버 주소가 바뀌므로). 그래서 DB 사용자 비밀번호를 길고 무작위로 둔다.
- Firestore에서 옮기기: `FIREBASE_SERVICE_ACCOUNT=… MONGODB_URI=… node scripts/copy-to-mongo.mjs maeumbit_` (같은 `SESSION_SECRET`이면 넣어 둔 AI 키도 그대로 풀린다).
- Firestore 규칙은 브라우저 접근을 모두 막는다(`firestore.rules`). 읽기·쓰기는 서버의 관리자 SDK만.
- 교사가 넣은 API 키는 `SESSION_SECRET`으로 암호화해 저장한다. 이 값을 바꾸면 키를 다시 넣어야 한다.

## Vercel 배포

환경 변수 `SESSION_SECRET`, `FIREBASE_SERVICE_ACCOUNT`, `TEACHER_PASSWORD`(4자리보다 길게)를 넣고 배포한다. `.env.example` 참고.
